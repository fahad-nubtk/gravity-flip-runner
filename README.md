## About the Game
Gravity Flip Runner is a 2D endless runner. Your character runs automatically and you flip gravity to switch between the floor and the ceiling, dodging obstacles for as long as you can. The farther you run, the higher your score.

## How to Play
| Key | Action |
|-----|--------|
| `SPACE` | Flip gravity |
| `R` | Restart after game over |
| `ESC` | Quit |

## Features
- Graphical game window
- Player character controlled with the keyboard
- Gravity flip between floor and ceiling
- Moving obstacles that spawn on the floor and ceiling
- Collision detection between the player and obstacles
- Live score shown on screen
- Game-over screen showing the final score
- Restart and quit options
